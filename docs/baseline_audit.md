# Baseline Audit Report

## Project
AI Student Academic & Career Assistant

## 1. Current Workflow
Students may use separate tools or manual processes for:
- Understanding academic concepts
- Creating study schedules
- Improving CVs
- Practicing interview questions
- Drafting professional emails

## 2. Initial Problems to Investigate
- Repeatedly writing similar prompts
- Inconsistent answer formats
- Missing context in user requests
- Difficulty checking response quality
- No centralized evaluation record

These are initial hypotheses to validate, not measured findings.
