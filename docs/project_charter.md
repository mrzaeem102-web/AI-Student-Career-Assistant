# Project Charter
## AI Student Academic & Career Assistant

### 1. Project Overview
Build an AI-powered assistant that helps university students with
academic questions, study planning, CV improvement, interview
preparation, professional writing, and career guidance.

### 2. Problem Statement
Students often need help organizing their studies and preparing
for professional opportunities. Information and advice may be
scattered across different tools. This project aims to provide
a single, easy-to-use interface for common student tasks.

### 3. Objectives
- Build a simple conversational assistant.
- Use reusable prompt templates for different student tasks.
- Integrate an AI API.
- Create a web interface using Streamlit.
- Evaluate outputs using predefined test cases.
- Document limitations, testing, and usage instructions.

### 4. Target Users
University students, recent graduates, and early-career applicants.

### 5. Scope
Included:
- Academic explanations and study plans
- CV and interview preparation
- Professional email and writing assistance
- Prompt templates and response evaluation
- Streamlit interface and documentation

Excluded:
- Guaranteed academic grades or job placements
- Professional legal, medical, or financial advice
- Fabricated qualifications or CV achievements

### 6. Proposed Technology Stack
- Python
- OpenAI API
- Streamlit
- JSON
- Pandas
- Git and GitHub

### 7. Deliverables
Week 1: Baseline audit, project charter, KPIs, workspace.
Week 2: Prompt framework, core workflow, initial interface.
Week 3: Integration, testing, optimization, pilot evaluation.
Week 4: SOPs, portfolio case study, presentation, demo video.

### 8. Risks
- API access or usage costs
- Incorrect or unsupported AI responses
- Network interruptions
- Accidental exposure of API credentials
- Limited time for testing

### 9. Success Criteria
A runnable application, documented prompt templates,
repeatable test cases, measured evaluation results, and
clear setup and usage documentation.

### 10. Team
Member 1: Technical development and architecture.
Member 2: Use cases, prompts, test design, and evaluation.
Member 3: Project coordination, repository, documentation,
and presentation.

### 11. Timeline
Four-week project plan, with a 125-point target per week
and 500 points across the project.
