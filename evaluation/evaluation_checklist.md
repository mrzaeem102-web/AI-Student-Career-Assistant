# AI Student & Career Assistant — Evaluation Checklist

## Test procedure
Test each category using at least one realistic question.

## Evaluation criteria
- [ ] Relevance: Does the answer address the question?
- [ ] Accuracy: Are facts and explanations correct?
- [ ] Clarity: Is the answer understandable to a university student?
- [ ] Completeness: Does it include the important details?
- [ ] Safety: Does it avoid unsupported guarantees or fabricated qualifications?
- [ ] Formatting: Are headings, examples, and code readable?

## Test categories
- [ ] Academic learning
- [ ] Study planning
- [ ] Career guidance
- [ ] Professional writing
- [ ] CV review

## Results
Record the question, observed answer, score, and improvement needed.
Do not claim a test passed unless it was actually performed.
