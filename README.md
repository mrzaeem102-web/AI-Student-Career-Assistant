# AI Student Academic & Career Assistant

An AI Prompt Engineering & Chatbot Application designed to
support students with academic learning and career preparation.

## Features Planned
- Academic question answering
- Study plan generation
- CV improvement suggestions
- Interview preparation
- Professional writing assistance
- Reusable prompt templates
- Test-case-based evaluation

## Technology Stack
- Python
- OpenAI API
- Streamlit
- JSON
- Pandas

## Project Structure
- docs/: project planning and evaluation documents
- data/: test datasets
- tests/: validation scripts
- app.py: chatbot interface (to be developed)

## Setup
1. Install Python 3 and Git.
2. Create and activate a virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure your API credentials securely when implementing
   API integration.
5. Run the application using `streamlit run app.py`.

## Status
Week 1: Planning and baseline setup in progress.

## Limitations
AI-generated responses may be incorrect and should be reviewed.
The assistant does not guarantee academic or employment outcomes.
